Defects

Fixed during this audit

DEF-01, medium. Pressing Enter in the block form activated Save draft because that was the first submit button. On a published block, that can change the status to draft. The form now starts with an unnamed Save button, so Enter keeps the status selected in the form. Save draft and Update still set the status when those buttons are used. Fixed in the block form. Confirmed by QA-ED-01 and QA-BR-24.

Still open

DEF-02, medium on this local site and high if the same environment is exposed. QA-SEC-01 failed. The debug toolbar is injected into HTML responses, and the welcome page also prints that the environment is development. Remediation: set the application environment to production before the site is reachable beyond this machine, and confirm the toolbar is gone. This audit did not change that setting, because the local site is being used for development.
